CHECKLIST BALI — VERSION GITHUB SANS DOSSIER

Cette version est prête pour GitHub Pages avec TOUS les fichiers à la racine.

À uploader directement dans ton repository :
- index.html
- manifest.webmanifest
- sw.js
- icon-180.png
- icon-192.png
- icon-512.png
- README.txt

Ensuite :
1. GitHub → Settings
2. Pages
3. Source : Deploy from a branch
4. Branch : main
5. Folder : / (root)
6. Save

Puis ouvre l’URL GitHub Pages dans Safari sur iPhone :
Partager → Ajouter à l’écran d’accueil.

Les cases et notes sont sauvegardées localement sur l’iPhone.
